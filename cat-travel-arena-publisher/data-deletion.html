การลบข้อมูล / Data Deletion

แอปนี้เก็บเพียง Page Access Token ของเจ้าของเพจ ไม่เก็บข้อมูลส่วนบุคคลของผู้ใช้ทั่วไป
The app stores only the Page owner's access token and no personal data of other users.

  1. Facebook → Settings → Apps and Websites (แอพและเว็บไซต์)
  2. เลือก / select Cat Travel Arena Publisher → Remove / ลบ — สิทธิ์ถูกเพิกถอนทันที / access is revoked immediately
  3. คำขอลบข้อมูลอื่น: ส่งข้อความหาเพจ พี่เสือ & น้องยูสุ หรือเปิด Issue ที่ GitHub เราจะลบภายใน 30 วัน / Other requests handled within 30 days.
